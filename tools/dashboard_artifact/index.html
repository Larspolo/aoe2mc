How a ticket gets to main

The path of one change, from your issue to the main branch.

  1. YouWrite issues and comments, set the priority labels, answer decision tickets.
  2. TicketA run writes and sizes the ticket. A clear size:S ticket with an exact spec and a merged example gets the label lane:haiku.
  3. PacerReads the quota usage. Starts Haiku runs for the ready lane:haiku tickets first, then Opus runs for the rest of the target.
  4. Autopilot runAn Opus run claims the top ticket, a Haiku run only a lane:haiku ticket. It writes the code and tests, verifies, and opens a pull request.
  5. CI and automergeCI quick runs lint and the fast tests on the pull request. Automerge merges it when CI is green.
  6. MainThe nightly CI runs the slow and the Minecraft tests; a red night opens an urgent ticket.

Around this path: each run refills the queue from the open epics, closes finished epics and reports on the status issue. A regular process review changes the skills, tools and CI. Unconflict merges main into pull requests that have a conflict.

Model lanes

Two kinds of autopilot run share the quota (issues 1715 and 1727). Clear, templated tickets go to the cheaper Haiku runs. Now: — open lane:haiku tickets, — of — runs on the Haiku lane.

Opus lane
Started by
Scheduled task “aoe2mc autopilot”: hourly at :06, and the pacer fires it.
Tickets
The top ready ticket. A lane:haiku ticket only when no other ticket is ready.
Work
The full cycle: feedback, triage, the ticket, epic checks, the queue refill, the roadmap and process reviews.
Quota
One run counts 1 in the target of the pacer.
Haiku lane
Started by
Scheduled task “aoe2mc autopilot haiku” (model Haiku): no schedule, only the pacer fires it, a new session each time.
Tickets
Only lane:haiku: size S, each file and value named, a merged PR with the same pattern, verify level 1. A ticket that is not clear loses the label and goes to Opus.
Work
The tickets only: no epic check, queue refill, roadmap or process review. Stops when no lane:haiku ticket is ready.
Quota
One run counts 0.25 (start value in agent.toml) until framework/tools/health.py measures the weight from 10 usage intervals with Haiku runs.
